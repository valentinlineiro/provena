## Overview

Provena `v0.7.0` completes the transition from a static professional profile compiler to a **Continuous Market Observer and Attention System**.

This release introduces an explicit governance architecture (ADR-001), synchronizes versioning across all monorepo packages, establishes the Shared Market Architecture (O2) in production, and provides an Attention Inbox for decision-filtered job opportunities.

---

## Key Highlights

### 1. Shared Market Architecture (O2)
- **Continuous Market Ingestion**: Automated ingestion of job postings from board APIs (e.g. Greenhouse public board API).
- **Deduplication Engine**: Deterministic `makePostingDedupeKey` preventing duplicate postings across sync runs.
- **Global PostgreSQL Persistence**: `@provena/market-postgres` repository implementing schema storage for opportunities, postings, and market model records.
- **Autonomous Cloudflare Workers Cron Sync**: Cloudflare Workers scheduled handler running background synchronization.

### 2. Attention Inbox (`/opportunities`)
- **Semantic Attention Tabs**: Categorizes opportunities into `Needs Attention`, `Worth Considering`, `Unresolved`, and `Decided`.
- **Base64URL Keyset Cursor Pagination**: Infinite scroll and deterministic pagination.
- **Candidate Preference Alignment**: Evaluates compensation thresholds, work modes, and role levels against candidate preference criteria.

### 3. Architectural Reconciliation & Governance
- **Architecture Freeze Record ([`freeze-v0.7.0.md`](file:///home/valentin/code/provena/docs/architecture/freeze-v0.7.0.md))**: Clear classification of Stable subsystems (Identity, Protocol v1, O2, Attention Inbox), Experimental research (K12), and Planned vision (Attention Validation).
- **Version Alignment**: Raíz and all `packages/*/package.json` synchronized to version `0.7.0`.
- **Operational Knowledge Versioning**: Version fixed at `0` for production operational knowledge until experimental K12 models are promoted.
- **Clean In-Memory Fallbacks**: Graceful fallback to Cloudflare KV / local in-memory storage when `DATABASE_URL` is omitted.

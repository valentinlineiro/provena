# True Holdout: Real-world Virgin MLOps Platform Engineer Job Posting

Role: MLOps Platform Engineer (Remote)

About the Role
We are looking for an MLOps Platform Engineer to design, build, and maintain the infrastructure and automated pipelines required to operationalize machine learning models. The primary goal is to ensure that models move efficiently from experimental environments (notebooks, Databricks) into scalable, reliable production systems.

Key Responsibilities
- Design and maintain end-to-end CI/CD/CT (Continuous Integration, Deployment, and Training) pipelines for ML models.
- Utilize MLflow for experiment tracking, model registry, model versioning, and artifact management.
- Deploy and manage containerized ML services on Kubernetes (EKS/GKE) using Docker.
- Orchestrate distributed model training and batch/real-time inference on the Databricks platform.
- Implement observability and monitoring for model performance, data drift detection, and automated retraining triggers.
- Automate cloud infrastructure provisioning using Terraform and Infrastructure as Code.
- Manage feature store integration and model governance across environments.

Technical Requirements
- 3+ years experience in MLOps or ML Platform Engineering.
- Strong proficiency in Python and PySpark.
- Hands-on experience with Databricks, MLflow, and Kubernetes.
- Experience with Cloud providers (AWS / GCP / Azure) and Docker.
- Solid understanding of CI/CD automation tools (GitHub Actions, GitLab CI).

# Control #1: HashiCorp (Senior Software Engineer — Cloud Infrastructure / Platform)

About HashiCorp
HashiCorp is a leader in multi-cloud infrastructure automation software. We build tools like Terraform, Vault, Consul, and Nomad that enable organizations to provision, secure, connect, and run any application on any cloud.

Role Overview
We are looking for a Senior Software Engineer to join our Core Infrastructure team. You will work on building scalable, distributed systems for infrastructure provisioning and security automation.

Key Responsibilities
- Architect and develop high-throughput, fault-tolerant distributed systems in Go and Python.
- Contribute to Terraform providers and cloud infrastructure automation tools.
- Design resilient APIs and microservices deployed on Kubernetes and AWS.
- Collaborate with security and operations teams to ensure high availability and continuous compliance.

Requirements
- 5+ years of software engineering experience in distributed systems.
- Strong proficiency in Go, Python, or Rust.
- Deep understanding of Cloud Architecture (AWS / GCP / Azure) and Kubernetes.
- Experience with CI/CD pipelines, automated testing, and Infrastructure as Code.

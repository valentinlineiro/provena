Role: Senior Data Engineer – Agentic AI & Data Infrastructure Modernization (Remote)

Job Summary
We are seeking a Senior Data Engineer to join our AI infrastructure team. In this role, you will bridge the gap between traditional big data engineering and modern Agentic AI workflows. You will be responsible for building, optimizing, and scaling data pipelines using PySpark and AWS Glue to accelerate legacy ETL modernization and power LLM agentic systems.

Key Responsibilities
- Architect, develop, and maintain high-performance ETL/ELT pipelines using PySpark and AWS Glue to process large-scale batch datasets.
- Design and deploy serverless data architectures using AWS Glue, AWS Lambda, Step Functions, and PySpark.
- Integrate LLM agents and multi-agent reasoning workflows into automated data processing and validation pipelines.
- Migrate legacy ETL platforms (Ab Initio / Informatica) to modern cloud-native PySpark environments using generative AI code generation.
- Implement robust error handling, monitoring, data quality checks, and resilience protocols across distributed data pipelines.

Requirements
- 5+ years experience in software engineering and data engineering with Python and PySpark.
- Hands-on experience with AWS Glue, PySpark, and distributed computing frameworks (managing 100+ jobs).
- Demonstrated experience integrating LLM APIs (Claude API / OpenAI) and building agentic AI patterns.
- Strong proficiency in Python, design patterns, automated testing, and CI/CD pipelines.
